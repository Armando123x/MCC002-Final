\section{Diccionario de variables}
\label{sec:diccionario}

El conjunto de datos contiene veinte variables predictoras y una
variable de clasificación. Para mantener la trazabilidad entre la fuente,
el notebook y el informe, se conservan los códigos originales del archivo
\texttt{german.data}. Los nombres en español se utilizan como
identificadores analíticos y no alteran los valores almacenados en el
dataset.

Esta decisión resulta importante porque varias columnas no representan
mediciones continuas, aunque estén registradas mediante números. Por
ejemplo, \variable{tasa_cuota} y \variable{anios_residencia} utilizan
valores enteros de 1 a 4, pero estos valores identifican niveles ordenados
y no cantidades observadas directamente. Del mismo modo, códigos como
\texttt{A65} y \texttt{A124} corresponden a categorías válidas y no deben
interpretarse como valores faltantes.

\subsection{Variables derivadas para el análisis}

forman parte del archivo original, sino que se generan durante el
preprocesamiento para facilitar el análisis y la presentación de los

La respuesta binaria queda definida formalmente como:

\[
Y_i =
\begin{cases}
0, & \text{si } \variable{clase}_i = 1
     \quad \text{(buen riesgo)},\\[3pt]
1, & \text{si } \variable{clase}_i = 2
     \quad \text{(mal riesgo)}.
\end{cases}
\]

Esta recodificación sitúa al mal crédito como clase positiva. En
consecuencia, el \textit{recall} mide la proporción de créditos de mal
riesgo que el modelo consigue identificar. También permite expresar
directamente como falso negativo el error de clasificar un mal crédito
como buen riesgo, que es el error de mayor costo en la matriz definida
por el dataset.

\subsection{Consideraciones de interpretación}

El diccionario contiene variables que requieren especial cautela. En
particular, \variable{estatus_personal_sexo} combina dos características
en una sola codificación histórica, mientras que
\variable{trabajador_extranjero} representa una condición potencialmente
sensible. Estas variables no deben interpretarse como causas del riesgo
ni utilizarse para justificar decisiones individuales sin una revisión
de equidad, regulación y pertinencia operacional.

Asimismo, las categorías ``desconocido'' o ``sin cuenta'' no se
reemplazan por valores faltantes. En un proceso de originación, la falta
de una cuenta o de información documentada puede constituir una señal
observable del perfil evaluado. Sin embargo, agrupar ambas situaciones
en un solo código limita la interpretación: no es posible determinar si
el solicitante carecía del producto financiero o si la información
simplemente no estaba disponible.

Estas restricciones serán consideradas al interpretar las asociaciones
marginales y los coeficientes de los modelos, evitando atribuir un
significado más preciso del que permite la documentación original.
